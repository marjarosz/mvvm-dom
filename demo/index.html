YOUR TURN

From a property
to a possibility.

Install the package. Create a model. Connect your first view.

01

Install

npm install mvvm-dom

ES modules and TypeScript declarations included.

02

Write a template

<template id="hello">
  <input data-bind="{value: name,
    mode: twoWay, triggerType: input}">
</template>
03

Connect your model

import { View, ViewModel } from 'mvvm-dom';

const model = new ViewModel();
model.registerProperty('name', 'Hello!');
const template = document.getElementById('hello');
if (!(template instanceof HTMLTemplateElement)) {
  throw new Error('Missing template');
}
const view = new View(template, model);
document.body.append(...view.viewNodeList);

// When you're done:
// view.dispose();
